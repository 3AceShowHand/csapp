# csapp
Todos los laboratorios para el estudio autodidacta de Sistemas Computacionales.

* lab0-cprogramminglab: Una implementación simple de la estructura de datos cola en lenguaje C.
* lab1-datalab: Un experimento de manipulación binaria, donde se implementaron algunas funciones interesantes.
* lab2-bomb: Ingeniería inversa de un programa bomba.
* lab3-attack: Inyección de código para atacar un programa y cambiar su comportamiento predeterminado.
* lab4-cache: Un programa simple para transponer matrices, intentando minimizar los fallos de caché (cache miss), y otro programa de simulación de caché.
* lab5-sh: Un programa de shell simple.
* lab6-malloc: Una librería malloc simple.
* lab7-proxy: Un programa proxy http/1.0 simple.

No todos los laboratorios han sido implementados, es posible que se añada código en el futuro.
